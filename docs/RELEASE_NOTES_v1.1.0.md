# 流存 v1.1.0

用于发现并保存你有权下载的 HLS / M3U8 点播视频的 Chrome Manifest V3 扩展。

## 下载与安装

下载本次 Release 附件 `liucun-m3u8-1.1.0.zip`，解压到固定目录，打开 `chrome://extensions` → 开启开发者模式 → 加载已解压的扩展程序 → 选择直接包含 `manifest.json` 的目录。

本发行包采用本地加载方式，不是 Chrome 网上应用店发行版。

## 功能

- 网页视频源发现、手动输入 M3U8、清晰度选择。
- 4 / 8 / 12 路并发，默认 8 路。
- 直接写入所选本地文件；兼容内存模式限制 512 MiB。
- 当前工作台内暂停、重试和续传。
- 对支持的同域目录签名，在来源页面产生新签名后继续下载，可选自动刷新来源页面。
- 支持点播 TS、固定初始化分片的 fMP4、普通 AES-128 和字节范围。

## 限制

不支持直播、DRM、独立音视频轨合并、时间线切换或转码。关闭或重新加载工作台后无法恢复进度。网站授权、限速和编解码器兼容性可能影响结果，不保证所有网站可用。

请仅保存有权下载的内容。反馈问题时不要公开签名令牌、Cookie 或私人视频地址。
