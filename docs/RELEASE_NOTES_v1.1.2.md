# 流存 v1.1.2

改进短时签名视频的续传提示。来源页自动刷新后，浏览器可能阻止播放器自动播放，导致下载一直等待新签名。工作台现在明确提示这个原因，并提供“打开来源页并播放”按钮；点击会切换到经来源域名验证的原标签页，用户在网站播放器点击播放后，原工作台继续等待合法的新请求。

此更新不会延长网站签名的有效期，也不会自动播放来源视频或跨 CDN 复用签名。暂停、等待和已完成分片仍保留在原工作台；网站更换 CDN 地址时，旧任务可能无法自动续传。

40 项自动化测试和本地 Chrome UI 回归通过。此版本尚未在真实视频来源页重新加载测试。请先完成正在进行的下载，再更新扩展；重新加载扩展会丢失未完成任务的进度。

下载 `liucun-m3u8-1.1.2.zip`，解压到固定目录，在 `chrome://extensions` 开启开发者模式并选择“加载已解压的扩展程序”，指向直接包含 `manifest.json` 的目录。

仅下载你有权保存的内容。Chrome 网上应用店尚未上架；本发行包不会自动更新。支持邮箱：white@ditto.rocks。
