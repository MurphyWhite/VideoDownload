# 流存 v1.1.1

修复某些 CDN 的签名目录路径比实际播放列表路径短一层时，选择清晰度后子列表请求丢失签名并返回 HTTP 403 的问题。签名仍只用于同一来源、同一完整资产目录；不同日期下同名资产不会互相续签。

发布前 39 项自动化测试通过。实际 Chrome 上重新载入来源页后，清晰度子列表成功解析；短时下载到 68 个分片，签名更新后继续下载并可暂停。尚未完成整部视频的保存与播放验证。

下载附件 `liucun-m3u8-1.1.1.zip`，解压到固定目录，在 `chrome://extensions` 开启开发者模式并选择“加载已解压的扩展程序”，指向直接包含 `manifest.json` 的目录。已安装旧版本请先完成当前下载，再用新版文件替换并重新加载扩展。

仅下载你有权保存的内容。Chrome 网上应用店尚未上架；本发行包不会自动更新。
