# 流存 v1.1.3

修复网站更换 CDN 地址或日期目录后，旧下载任务一直等待原 CDN 新签名的问题。任务暂停后，先在来源页刷新并播放，再点击工作台的“检查新 CDN 并续传”。扩展会寻找原清晰度，对比播放列表全部分片结构，并重新请求首个和最后一个已写入分片进行 SHA-256 抽样核对；通过后保留已写入进度并继续下载。

不会把新 CDN 的签名用于旧地址。原清晰度缺失、结构或抽样内容不同、没有可校验的已下载媒体分片时，会保留任务并拒绝切换。抽样不能证明尚未下载的每个分片字节都相同。

更新前请完成已打开的旧版下载工作台；重新加载扩展会丢失该工作台的内存进度。此版本的本地合成视频测试覆盖跨 CDN 磁盘续传和拒绝情形；尚未在真实视频来源页重新加载测试。

下载 `liucun-m3u8-1.1.3.zip`，解压到固定目录，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，指向直接包含 `manifest.json` 的目录。

仅下载你有权保存的内容。Chrome 网上应用店尚未上架；本发行包不会自动更新。支持邮箱：white@ditto.rocks。
